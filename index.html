How to add new exams
  1. Name the HTML file with the section number, then ~ , then its order and name:
    7 Cummings ~ 4 My new quiz.html
  2. To put it under a sub-heading, add it in the middle:
    7 Cummings ~ 9 Cummings Exams ~ 6 Cummings Mock — Paper 6.html
  3. For a new section, use a new number:
    10 Scott-Brown ~ 1 Volume 1 MCQs.html
  4. On GitHub, open the repository → Add file → Upload files → Commit changes.
  5. Wait 2 minutes, open the app with internet and tap Check for new exams.

The number decides where it goes. Renaming a file later resets its saved progress. Folders work too: a file in 10 Scott-Brown/ lands in section 10.
